# MeowChat 🐾

**내 이야기를 영어로 풀어주는, 기억하는 고양이.**

MeowChat은 현재 화면의 이야기로 대화하고, 말하고 싶었던 뜻을 영어로 표현하도록 돕는 Chrome 친구입니다.

사진을 참고한 검은 머리·흰 얼굴의 고양이에게 이름을 지어주세요. 관심사는 영어 키워드를 눌러 선택하거나 모두 건너뛸 수 있습니다. 처음부터 빈 입력창에 내 문장을 직접 적습니다. 텍스트가 기본이며 음성은 원할 때 켤 수 있습니다. 막히면 도움을 열고, 마지막에는 더 자연스러운 표현을 배웁니다. 작은 고양이를 누르면 현재 페이지로 이야기합니다. 기억해둔 이야기가 있으면 현재 화면과 지난 이야기 중 선택할 수 있습니다. 한국어 글도 소재가 됩니다. 사용자의 목표는 난이도와 대화 능력을 조절하고, 현재 콘텐츠가 이야기의 주제를 정합니다.

[서비스 소개](https://sieunkim99.github.io/routine-english/) · [최신 설치 파일](https://github.com/sieunkim99/routine-english/releases/latest/download/routine-english-extension.zip) · [사용자 스터디 가이드](USER_STUDY_GUIDE.md) · [설정·대화 체험](https://sieunkim99.github.io/routine-english/) · [고양이 디자인 미리보기](https://sieunkim99.github.io/routine-english/buddy-demo.html)

서비스 소개 페이지에서 **Chrome 확장 다운로드** 또는 **설치 없이 체험하기**를 선택합니다. 체험에는 API 키가 필요 없으며 고정 예시로 기능을 살펴봅니다. 실제 AI 학습은 설치한 Chrome 확장에서 진행합니다.

확장의 **야옹 코치 설정 시작하기**를 누르면 MeowChat 소개 화면이 먼저 열리고, 소개 화면에서 설정으로 이어집니다. 설정을 마친 뒤에는 학습 설정을 바로 열 수 있습니다.

## 처음 한 번 설정

1. 설치 ZIP을 다운로드해 압축을 풉니다.
2. Chrome 주소창에 `chrome://extensions` → **개발자 모드** → **압축해제된 확장 프로그램 로드** → `manifest.json`이 있는 폴더를 선택합니다.
3. 고양이 이름·관심사 키워드를 선택적으로 정하고, 자동으로 열린 설정에서 데이터 전달 안내에 동의하고 **본인의 OpenAI API 키**를 입력합니다. 연결 확인에 작은 API 요청이 발생합니다. 서버·터미널은 필요 없습니다.
4. **목표는 나중에 · 바로 시작하기**로 목표 설정을 생략할 수 있습니다. 맞춤 계획을 먼저 만들려면 일상·원하는 영어 사용 장면·관심사를 세 번의 짧은 영어 대화로 알려주고 피드백과 계획을 확인합니다. 생략하면 수준은 미평가로 두며, 나중에 **학습 설정 → 목표·관심사 추가 / 수정**에서 보완합니다.
5. **현재 화면으로 연습 → 고양이 친구 켜기**를 누르고 사이트 접근 권한에 동의합니다. 고양이가 웹페이지 모서리에 표시됩니다. 이 기능은 선택 사항입니다.

현재 Chrome 웹 스토어 등록 전 버전입니다. Chrome 120 이상이 필요합니다. 키 사용 요금은 본인 OpenAI 계정에 발생하며, ChatGPT 구독과 별개입니다. 키를 다른 사람에게 보내거나 소스에 넣지 마세요.

## 평소에는 두 가지

### 지금 화면으로 스몰톡

고양이를 누르면 해당 페이지를 가져와 짧게 이야기합니다. 게시물의 책·문학·취미 같은 실제 내용이 주제가 됩니다. 사이트명이나 직업만으로 연구 소개를 반복하지 않습니다. 본문이 읽히지 않으면 사이트 정보만으로 지금 무엇을 하는지 묻고, 이미지나 게시물을 봤다고 주장하지 않습니다.

빈 입력창에 **내가 하고 싶은 말을 영어로 직접 적어** 대화를 이어갑니다. 선택지나 단순 단어 답변 예시를 먼저 보여주지 않습니다. 완성된 문장으로 생각을 표현하되, 짧게 답하거나 틀려도 괜찮습니다.

영어가 생각나지 않으면 **몰래 도움받기**를 누릅니다. 한국어·영어를 섞어 뜻을 알려주면 야옹 코치가 내 의미를 살린 문장·핵심 표현·설명을 준비합니다. **이 표현으로 말해보기**로 돌아와 직접 써봅니다. 초안은 본 대화에 자동 제출되지 않습니다. ‘무슨 말을 할지 같이 생각하기’로 생각을 넓힐 수도 있습니다.

세 번마다 표현을 돌아보고 **조금 더 이야기하고 츄르 주기**로 계속할 수 있습니다. **대화 마치고 표현 보기**로 일찍 끝내도 됩니다. 한국어 해석은 숨기거나 펼칠 수 있습니다. 대화와 몰래 도움 요청은 API 요금이 발생하며 카드 복습에는 추가 AI 요청이 없습니다.

선택 문장이 있으면 그것을, 없으면 화면에 보이는 본문을 우선 사용합니다. **이 내용으로 이야기해요**를 펼치면 질문의 근거 문구를 확인할 수 있습니다. 원문 인용 검사는 근거를 확인하는 장치이며 모델의 의미적 정렬을 완전히 보장하지는 않습니다.

마이크는 **음성 대화 시작**을 눌렀을 때 요청합니다. 잠깐 쉬어도 자동 제출되지 않으며 **말하기 완료 · 보내기**로 제출합니다. 야옹 코치가 말할 때와 화면이 숨겨질 때는 녹음을 멈춥니다. 브라우저 음성 제공자가 오디오를 처리할 수 있으며 발음 평가는 하지 않습니다.

고양이를 켜지 않아도 Mac **⌘⇧Y**, Windows/Linux **Ctrl+Shift+Y** 또는 Chrome 오른쪽 위 **퍼즐 모양 확장 프로그램 → MeowChat 고정**으로 열 수 있습니다. 단축키 충돌은 `chrome://extensions/shortcuts`에서 변경합니다.

### 기억해둔 이야기와 고양이 행동

대화 뒤 **이 이야기 기억해줘**를 누르면 표시된 주제·요약·다음 질문을 저장합니다. 다음 학습 화면이나 제안 창의 **지난 이야기 이어가기**에서 다시 열 수 있습니다. 설정에서 **이어갈 목록에서 빼기**로 저장한 주제를 제거할 수 있습니다. 기존 대화·표현 기록은 유지합니다. 전체 화면 내용을 자동으로 기억하거나 관심사를 추측해 저장하지 않습니다. 현재 화면이 기본 소재이며 기억한 이야기는 사용자가 선택해 이어갑니다.

오늘 대화와 표현 복습의 활동 정도에 따라 꼬리 움직임·기지개·귀여운 자세를 보여주며, 츄르를 주면 먹는 움직임을 보여줍니다. 제안에 여러 번 응답하지 않으면 조용히 웅크리며 재촉하지 않습니다. 학습 실패나 이른 종료에 벌을 주지 않습니다.

### 완성 표현 카드 복습

대화 전체에서 다듬은 표현·몰래 도움받은 문장·잘 표현한 문장을 핵심 표현과 짧은 피드백으로 모읍니다. **오늘 모은 표현**에서 복습에 넣거나 뺄 수 있고 같은 문장은 합칩니다. **뜻·상황을 보고 떠올리기 → 완성된 표현 보기 → 듣기 → 기억 상태 선택**으로 복습합니다. 과거 대화를 그대로 다시 진행하거나 전체 문장을 타이핑할 필요가 없습니다. ‘완성된 표현 모아보기’에서 전체 표현과 다음 날짜도 볼 수 있습니다.

초기 간격은 **10분 → 1일 → 3일 → 7일 → 14일 → 30일**입니다. 잘 떠올리면 늘리고, 힘들거나 잊었다면 줄입니다. 망각·회상·간격 학습 연구를 참고한 초기 규칙이며 개인의 기억률을 측정한 정확한 망각곡선이나 검증된 최적 간격은 아닙니다. 버튼은 자기평가입니다. 카드 복습에는 추가 AI 호출이 없습니다. [자세한 복습 설계](docs/EXPRESSION_REVIEW.md)

## 제안과 회의 전 방해금지

학습 설정에서 **고양이가 말 걸기 / 작은 채팅창 팝업 / 알림** 중 하나를 선택하고, 일정 간격 또는 정해진 시각(예: `14:00, 18:30`)을 정합니다. 고양이는 제안 시 잠깐 움직이며 말풍선을 표시합니다. 누르지 않으면 자동으로 대화를 시작하거나 API를 호출하지 않습니다.

회의 전 야옹 코치 화면의 **회의 전 방해금지**, 또는 고양이 옆 **⋯ → 1시간 조용히 기다리기**를 선택합니다. 이 서비스의 제안을 멈추며 종료 시각 뒤 자동으로 다시 제안할 수 있습니다. 앱 내 제안 제어이며 회의를 자동 감지하는 기능은 아닙니다.

컴퓨터가 쉬거나 잠겼을 때, 학습 중, 방해금지 중에는 제안을 건너뜁니다. Chrome이 실행 중이어야 하며 실제 표시 시각은 지연될 수 있습니다. 정해진 시각의 제안은 이후 5분 안에서만 한 번 가능하고 놓친 것을 몰아서 보여주지 않습니다. 일반 패키지의 Chrome 알람은 최소 30초 제약이 있고 개발자 모드 설치는 예외입니다.

## 권한과 데이터

고양이를 켜기 전에는 `activeTab`으로 명시적으로 호출한 페이지에 접근합니다. 고양이는 여러 사이트에 계속 표시해야 하므로 **선택적 HTTP/HTTPS 사이트 접근 권한**을 켤 때 요청합니다. 고양이 스크립트는 표시·버튼·제안만 처리하고 페이지 본문을 계속 수집하지 않습니다. 클릭하면 worker가 본문/선택 문장 최대 6,000자를 가져와 목표·최근 기록과 함께 OpenAI로 전송해 스몰톡을 시작합니다. 고양이를 끄면 등록과 선택적 사이트 권한을 해제합니다. Chrome 내부 페이지·웹 스토어 등 보호된 화면에는 표시되지 않을 수 있습니다.

API 키는 trusted-context-only `chrome.storage.local`에 저장하며 암호화된 금고는 아닙니다. 웹페이지·고양이 스크립트에는 키와 개인 학습 기록을 전달하지 않습니다. 학습 기록·복습 일정은 로컬에 남습니다. 요청은 OpenAI Responses API(`gpt-4o-mini`, Structured Outputs, `store:false`)로 직접 갑니다. `store:false`가 제공자의 모든 로그·보존이 없다는 뜻은 아닙니다. 이름·관심사·승인한 이야기 요약·도움 초안과 표현 기록도 로컬에 보관되며 관련 학습 요청 때 AI에 전달됩니다. 운영 서버·공유 키·분석 추적은 없습니다. [데이터 안내](PRIVACY.md)

## 에이전트와 학습 근거

야옹 코치는 **목표/관심 이해 → 현재 소재와 난이도 선택 → 먼저 의미 표현 → 종료 후 실제 발언 기반 피드백 → 표현별 회상 기록과 다음 제안 조절**을 연결합니다. 사용자가 매번 학습 과제와 다음 날짜를 정할 필요가 없습니다. 직접 만든 문장과 몰래 도움받은 표현의 적용을 구분해 기록합니다. 후속 카드에서 답을 보기 전 떠올리는 회상과도 구분하며, 도움받은 성공을 독립 실력이나 장기 기억으로 평가하지 않습니다. 목표 변경은 사용자가 승인합니다.

[실제 프롬프트와 평가 기준](docs/COACH_PROMPTS.md) · [목표와 동기 설계](docs/MOTIVATION_DESIGN.md) · [표현 학습 근거](docs/CHUNK_LEARNING.md) · [간격 복습 근거와 한계](docs/EXPRESSION_REVIEW.md)

교육 원리가 완성된 서비스의 효과를 입증하지는 않습니다. 실제 모델의 개인화 품질·사용성·지연 회상·새 상황에 적용하는 능력을 별도로 평가해야 합니다.

## 고양이가 안 보이면

고양이는 기본적으로 꺼져 있습니다. 첫 학습 화면에서 **고양이 친구 켜기**를 눌러 권한을 허용하세요. 켰는데 안 보이면 **고양이 다시 표시**를 누르고 일반 웹페이지를 새로고침합니다. Chrome 설정·다운로드·웹 스토어 같은 보호된 화면에는 표시할 수 없습니다.

## 업데이트 / 개발

기존 설치 폴더의 파일을 새 ZIP 내용으로 교체 → `chrome://extensions`에서 새로고침 → 열려 있는 야옹 코치 화면 다시 열기. 같은 폴더를 유지하면 API 키·목표·기록이 유지됩니다. 진행 중이던 옛 버전 대화는 닫고 새로 시작합니다.

Node.js 22 이상, 외부 패키지 없이 개발할 수 있습니다.

```sh
npm test
npm run build
npm run dev
```

로컬 미리보기는 `http://127.0.0.1:5173/`이며 실제 사용에는 서버가 필요 없습니다. 공개 미리보기는 고정 예시이고 실제 키를 받지 않습니다. 라이브 AI는 설치한 확장에서 동작합니다.

빌드 결과: `dist/extension`, `dist/routine-english-extension.zip`, `dist/web`. GitHub workflow가 테스트·빌드·GitHub Pages 게시를 수행합니다. source: `shared/app.js`, `shared/controller.js`, `shared/state.js`, `shared/prompts.js`, `shared/ai.js`, `extension/background.js`, `extension/buddy.js`, `extension/extract.js`.

자동 테스트는 모의 AI/Chrome API를 사용합니다. 실제 API 품질, 네이티브 설치·권한·마이크·운영체제 알림과 고양이 동작은 기기에서 확인해야 합니다. MIT 라이선스로 공개합니다. 이슈·소스·릴리스에 API 키나 개인 학습 자료를 올리지 마세요.

## 화면 읽기와 고양이 활동 반응

[화면 읽기 가이드](docs/SCREEN_CONTEXT_GUIDE.md): 선택한 문단, 현재 보이는 텍스트 본문을 우선 사용합니다. 기사·블로그·웹문서가 잘 맞고, 인스타그램은 사진 대신 캡션을 읽습니다. 이미지·영상·PDF 뷰어·보호된 Chrome 화면은 제한됩니다.

같은 페이지에서 스크롤/게시물/탭을 바꾸면 **현재 화면 다시 읽기 ↻**를 누릅니다. 읽기는 로컬에서만 처리합니다. 내용이 바뀐 대화에서는 새 내용을 확인한 뒤 **대화 피드백을 저장하고 새 화면으로 시작**을 선택합니다. 기존 질문에 새 맥락을 섞지 않습니다.

한국어 해석은 기본 숨김이고 **한국어 해석 보기**로 펼칠 수 있습니다. 이번 업데이트에서 기존 기본 표시도 한 번 숨김으로 전환하며 이후 선택은 기억합니다. 복습 앞면의 한국어 상황 단서는 별도 유지합니다.

고양이는 오늘 저장한 대화 응답과 복습한 서로 다른 표현에 따라 꼬리 살랑→기지개→신난 자세로 반응합니다. 같은 카드의 반복 버튼 누르기로 단계를 올리지 않고, 정답률이나 영어 실력을 평가하는 지표로 사용하지 않습니다. 츄르와 방해금지, 조용히 웅크리기는 유지합니다.
