# 현재 화면의 스몰톡에서 표현 배우기

0.9.0부터 새 페이지 연습은 실제 콘텐츠에 대한 짧은 스몰톡이다. 먼저 학습자 의미를 표현하게 하고, 자연스러운 표현 제안은 대화 종료 후 제공한다. 한두 단어나 구도 받아들이며, 즉시 도움이 필요할 때는 지원한다. 아래 0.7.0의 선택·빈칸 과정은 현재 **복습**에서 활용한다.

대화 마지막에 원문 인용·자연스러운 대안·간단한 설명을 보여준다. 원문이 이미 맞으면 대안은 선택 가능한 확장으로 표시한다. 유용한 표현을 얻으면 다음 날 복습하도록 기록한다. 이는 의도적 표현 학습·회상·분산 학습을 대화에 연결한 제품 설계이며, 대화 후 피드백이 모든 학습자에게 최적이라는 주장이나 검증된 제품 효과는 아니다.

# 작은 표현을 익히는 맥락 기반 학습

0.7.0 · 2026-10-14

완성된 문장을 처음부터 만들기보다 쓸모 있는 표현 하나를 알아보고, 도움을 줄여 떠올리고, 본인의 의미를 넣어 사용한다. 에이전트는 어떤 표현·어떤 형태·얼마나 도움을 줄지를 페이지의 실제 내용과 사용자 목표/관심사·최근 수행으로 결정한다.

## 화면의 학습 흐름

1. **새 표현 알아보기:** 짧은 상황 + 표현 보기 2–3개. 버튼을 누르거나 목소리로 선택할 수 있다. 마이크 허용 없이도 시작 가능하다.
2. **떠올리기:** 성공하면 같은 표현을 빈칸에서 회상한다. 답안 선택지는 사라지고 현재 과제만 표시한다. 모르는 표현은 먼저 노출한 뒤 연습한다.
3. **나에게 맞게 바꾸기:** 준비되면 사람·취미·장소 같은 작은 부분을 바꾼다. 단어나 짧은 chunk도 답으로 인정한다.
4. **나중에 다시 쓰기:** 실제 연습한 chunk와 과제 형태, 응답을 저장한다. 복습은 같은 표현을 보기 없이 떠올리는 빈칸/짧은 응답부터 시작한다. 막혔으면 지원을 다시 늘린다.

이 순서는 기본 틀이다. 이미 알고 있는 표현은 빈칸부터 시작할 수 있고, 어려워하면 선택형이나 부분 도움으로 돌아간다. 사용자가 원하는 경우 음성/자유 응답도 가능하다. 선택만 성공한 기록은 독립 회상 점수 2를 받을 수 없다. 빈칸 회상이나 개인화한 단어 하나도 전체 영어 능력의 습득을 입증하지 않는다.

## 맥락 선택의 기준

Notion을 열었다는 이유로 연구 소개 문장을 주지 않는다. 본문에 있는 구체적인 행동·결정·문제·반응을 찾고, 사용자에게 어떤 표현이 유용할지 연결한다. 예시는 실제 페이지에 해당 상황이 있을 때만 사용할 수 있다.

| 본문의 실제 상황 | 가능한 chunk | 짧은 과제 |
| --- | --- | --- |
| 마감일 연기 제안 | push back the deadline | ‘미루다’ 표현 선택 → Could we ___? → 바꿀 날짜 한 단어 |
| 역할 분담 논의 | split up the work | 상황에 맞는 표현 선택 → Let's ___ → 맡고 싶은 일 짧게 |
| 다른 의견 제안 | see it differently | 반응 표현 선택 → I ___ → 본인의 이유 한 단어/구 |
| 콘텐츠를 나중에 보고 싶음 | save it for later | 의미 선택 → I'll ___ → 저장할 콘텐츠 종류 한 단어 |

인스타그램 사이트 정보만 있으면 실제 게시물은 모른다. 저장·공유·넘겨보기 같은 행동을 선택 가능한 상황으로 제시하고 사용자 의도를 확인한다. 사진·게시물·개인 관심사를 봤다고 주장하지 않는다. 실제 읽은 글이 있으면 그것을 우선한다. 동일한 표현을 계속 재사용하지 않도록 최근 기록을 참고하되, 복습 시에는 의도적으로 다시 사용한다.

## 교육·심리 기반과 한계

- **Formulaic sequences:** 의미 있는 어구에 주의를 기울이고 의도적으로 기억·사용하는 설계를 참고했다. 특정 chunk 2–6단어 길이와 세 단계 UI는 제품 설계값이며 검증된 최적값은 아니다. [Boers & Lindstromberg, 2012](https://www.cambridge.org/core/journals/annual-review-of-applied-linguistics/article/abs/experimental-and-intervention-studies-on-formulaic-sequences-in-a-second-language/A2ACDF54604CFAC4443240748360C403)
- **회상·분산 학습:** 처음 본 표현의 선택은 학습 진입을 돕는다. 이후 보기 없는 회상과 다음 날 이후 복습을 연결한다. 선택형 정답률만으로 기억했다고 판단하지 않는다. [Dunlosky et al., 2013](https://journals.sagepub.com/stoken/rbtfl/Z10jaVH/60XQM/full)
- **적절한 어려움:** 이전 표현을 새로운 짧은 맥락에서 다시 사용하되, 막히면 단서를 제공한다. 인지적 마찰을 기계적인 문장 길이나 반복 실패로 만들지 않는다. [Bjork & Kroll, 2015](https://bjorklab.psych.ucla.edu/wp-content/uploads/sites/13/2016/11/ra_kroll_2015.pdf)

제품의 학습·재미·개인화 효과는 별도 평가가 필요하다. 같은 목표/페이지에서 과제의 구체성, 사용자가 느끼는 관련성·시작 부담, 다음 날 힌트 없는 회상, 다른 상황에 적용하는 능력을 확인한다. 자동 테스트는 API 전달·기록·형태·점수 제약만 확인한다. 실제 모델의 표현 선택을 검증한 것은 아니다.

## 코드

AI의 task 출력은 `mode(choice/gap/short)`, `cue`, `frame`, `choices`, `chunk`다. chunk는 내부 목표이며 UI에서 자동 공개하지 않는다. 모델 응답에는 실제 사용자에게 보여준 과제와 시도 형태를 함께 전달한다. 기록에는 chunk·각 응답의 과제 형태를 저장해 복습과 난이도 판단에 사용한다. 기존 대화 기록은 유지하며 새 기록부터 이 정보가 추가된다.
