# 완성 표현의 간격 복습

0.11.0 · 2026-10-14

복습 대상은 커리큘럼이나 과거 대화 전체가 아니라, 대화 후 얻은 **완성된 영어 표현**이다. 같은 능력 아래 여러 표현을 배워도 하나만 남기지 않고 각각 관리한다. 같은 표현은 대소문자·공백을 정규화하여 카드 하나로 모으고, 원래 대화 기록은 보존한다.

## 화면과 기록

- 뜻 또는 의도와 원래 상황을 보고 표현을 먼저 떠올린다. 타이핑·새 대화는 필수가 아니다.
- ‘완성된 표현 보기’를 누르면 큰 글씨의 영어 표현과 듣기 버튼을 보여준다.
- ‘다시 보고 싶어요 / 힘들게 떠올렸어요 / 잘 떠올랐어요’ 중 하나를 고르면 다음 복습 시점이 바뀐다.
- ‘완성된 표현 모아보기’에서 전체 표현과 뜻·다음 날짜를 쉽게 찾아볼 수 있다. 여기서 다시 떠올리기를 선택할 수 있다.
- 복습 기한이 지난 표현을 우선 제안한다. 오늘 기한이 없으면 다음 제안 시각과 선택적인 미리 복습을 보여준다.

새 대화의 피드백에서 표현 전체에 대응하는 짧은 한국어 의미(meaning)를 함께 받는다. 이전 기록에 이 의미가 없으면 원래 페이지 제목과 일반 회상 안내를 사용한다. 기존 기록을 번역하기 위한 추가 API 호출은 하지 않는다. 카드 조회·듣기(브라우저 합성)·기억 상태 기록·예약 계산에도 AI 호출이 없다.

카드 ID는 표현이 처음 저장된 대화 ID다. 표현별 expressionReviews에 단계·다음 시각·기억 상태 이력을 저장한다. 한 번의 답 공개 후 한 번의 기억 상태 기록을 허용한다. 카드 복습은 새 대화 완료나 커리큘럼 숙달로 기록하지 않는다.

## 망각곡선과 스케줄

시간이 지나며 기억이 약해지는 망각 연구와 회상·간격 효과를 참고한다. 다만 에빙하우스의 결과를 모든 사용자에게 맞는 고정 기억률 공식으로 적용하거나 실제 기억률을 측정했다고 표시하지 않는다. 최적 간격은 목표 보존 기간과 과제 등에 따라 달라진다. [Cepeda et al., 2008](https://laplab.ucsd.edu/articles/Cepeda%20et%20al%202008_psychsci.pdf)

초기 단계는 **10분 → 1일 → 3일 → 7일 → 14일 → 30일**이다. 새 표현은 저장 10분 뒤부터 제안 가능해진다. 잘 떠올랐다고 표시하면 한 단계 늘린다. 다시 보고 싶다고 표시하면 초기 단계로 돌아가 10분 뒤 다시 제안한다. 힘들게 떠올렸다면 단계는 유지하고 해당 간격을 절반으로 줄이되 10분보다 짧게 하지 않는다. 마지막 단계의 성공 간격은 30일이다.

이 숫자는 제품의 초기 휴리스틱이다. 개별 사용자에게 검증된 최적 간격, SM-2 또는 FSRS, 에빙하우스가 제시한 권장 일정이라고 부르지 않는다. 버튼은 **사용자의 자기평가**이며, 보기 전에 실제로 기억했는지 자동 판정하지 않는다. 반복 실사용으로 간격·부담·지연 회상 결과를 검증해야 한다.

알림과 팝업은 기존 사용자 지정 간격 또는 시각, 허용 시간대, 활동 상태, 방해금지를 따른다. 카드의 기한이 됐다고 즉시 강제로 팝업을 만들지는 않는다. Chrome이 쉬거나 종료돼 있으면 제안은 지연될 수 있다.

## 확인

자동 테스트는 같은 능력의 여러 표현 유지·중복 표현 통합·다음 간격 조절·한 번의 공개 뒤 기록·추가 AI 호출 없음·기존 대화 보존을 확인한다. 사용자의 기억 향상 자체를 검증하지 않는다.
