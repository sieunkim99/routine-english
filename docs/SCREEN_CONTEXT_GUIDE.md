# MeowChat 화면 읽기 가이드

## Google 사이트 정보만 나올 때

“The learner is currently on google.com...”은 검색 결과를 읽었다는 뜻이 아니라 **본문을 못 읽어 사이트 이름만 확인했다**는 내부 안내입니다. Google 홈처럼 본문이 적은 화면에서는 정상적인 제한일 수 있습니다. 검색 결과나 읽고 싶은 글을 연 뒤 **현재 화면 다시 읽기**를 누르세요. 필요하면 본문 문단을 선택합니다.

0.16.1부터 검색창에 포커스가 있어도 입력 값·입력란 선택은 제외하고 검색 결과 등 나머지 본문을 읽습니다. 페이지 구조나 권한에 따라 여전히 읽기가 제한될 수 있습니다.

이전의 ‘현재 화면에 근거한 질문을 준비하지 못했어요’는 AI의 자유 인용과 원문을 엄격히 대조하던 단계의 오류입니다. 0.16.1부터 실제 본문에서 만든 근거 후보 중 AI가 하나를 선택합니다. 번역·요약을 인용으로 잘못 쓰면서 생기던 불일치를 줄이고, 근거 없는 응답을 임의로 통과시키지는 않습니다.

MeowChat은 화면 사진을 분석하는 방식이 아니라, 요청한 웹페이지의 읽을 수 있는 텍스트를 가져옵니다. **선택한 문단이 최우선**, 선택이 없으면 현재 화면에 보이는 본문을 우선 사용합니다. 주변 문장이 함께 포함될 수 있고 최대 6,000자입니다.

| 화면 | 사용 팁 |
| --- | --- |
| 기사·블로그·텍스트가 있는 웹문서 | 원하는 본문이 보이게 스크롤하고 다시 읽기. 텍스트 중심 화면이 잘 맞습니다. |
| Notion 본문 | 읽고 싶은 문단을 보이게 하거나 선택. 검색창·입력 중인 폼 대신 본문을 사용합니다. 페이지 구조에 따라 읽기 범위가 달라질 수 있습니다. |
| Instagram 등 게시물 피드 | 사진보다는 캡션·본문이 소재입니다. 게시물/댓글/팝업을 바꿨다면 다시 읽고, 가져온 내용이 다르면 원하는 문단을 선택하세요. |
| 긴 피드·여러 게시물 | 스크롤 후 다시 읽기. 주제가 섞이면 **원하는 문단 하나를 선택**하는 방법이 가장 확실합니다. |
| 이미지 속 글·영상·PDF 뷰어 | OCR·음성·영상 분석을 지원하지 않아 내용 파악이 제한됩니다. 읽을 수 있는 웹 본문을 사용하세요. |
| Chrome 설정·웹 스토어 등 보호된 화면 | 본문 접근과 고양이 표시가 제한됩니다. 일반 웹페이지에서 사용하세요. |

본문이 부족하면 사이트 정보만으로 현재 활동을 이야기하며 보지 못한 게시물이나 이미지를 봤다고 주장하지 않습니다. 선택 문장은 너무 짧지 않게 **20자 이상인 문단**을 권합니다.

## 같은 주소에서 화면이 바뀌었을 때

1. 실제 웹페이지를 열어둔 상태에서 오른쪽 대화창의 **현재 화면 다시 읽기 ↻**를 누릅니다. 설정 탭보다 웹페이지 옆 대화창에서 사용하는 것을 권합니다.
2. **새로 읽은 내용 확인** 또는 **AI에 전달할 화면 정보 보기**에서 소재를 확인합니다. 다시 읽기 자체에는 AI 요청이 없습니다.
3. 대화 중 내용이 바뀌었다면 **대화 피드백을 저장하고 새 화면으로 시작**을 누릅니다. 기존 응답의 피드백을 저장하고 새 소재로 대화합니다. 응답이 없으면 바로 새 화면으로 시작합니다. 이 단계에는 AI 요청과 요금이 발생합니다.

새 화면을 읽었다고 기존 질문의 맥락을 몰래 바꾸지 않습니다. 가져온 내용이 다르면 원하는 문단을 선택하고 다시 읽으세요. 전체 사이트를 항상 정확히 읽는다는 보장은 없으며 페이지 구조·접근 권한·표시 방식에 영향을 받습니다.
