## RoutineEnglish 0.11.0 — 작은 고양이와 표현 카드 복습

- 선택적으로 웹페이지 모서리에 작은 고양이를 표시합니다. 예약 제안 시 움직임과 짧은 말풍선으로 말을 걸며, 누르면 현재 페이지로 스몰톡을 시작합니다.
- 설정의 ‘고양이 친구 켜기’에서 선택적 사이트 권한에 동의해야 표시됩니다. 고양이를 끄면 표시 등록과 선택적 권한을 해제합니다.
- 고양이 옆 ⋯ 메뉴에서 ‘1시간 조용히 기다리기’와 학습 설정을 바로 열 수 있습니다. 앱의 방해금지·활동 상태·학습 중 제안 제한을 따릅니다.
- 고양이 스크립트에는 API 키·프로필·학습 기록을 전달하지 않습니다. 페이지 본문은 고양이를 눌러 스몰톡을 시작할 때 worker가 가져옵니다. Chrome 내부/보호된 페이지에서는 표시되지 않을 수 있습니다.
- 복습은 완성 표현 카드로 변경했습니다: 뜻/상황 → 표현 공개·듣기 → 기억 상태로 다음 간격 조절. 전체 표현 모음과 다음 날짜도 제공합니다. 대화 전체를 다시 수행하지 않고 추가 AI 호출도 없습니다.
- README, 사용자 스터디 가이드, 개인정보 안내를 최신 사용 흐름으로 정리했습니다.

복습 초기 간격 10분 → 1일 → 3일 → 7일 → 14일 → 30일은 망각·분산 학습 연구를 참고한 설계값이며 개인의 정확한 망각곡선을 측정한 공식은 아닙니다.

업데이트: ZIP을 기존 폴더에 교체하고 chrome://extensions에서 새로고침 → 코치 화면 다시 열기 → 학습 설정에서 고양이 친구 켜기 → 사이트 권한 동의. 일반 웹페이지를 새로고침하면 나타납니다.

자동 테스트 42개와 빌드를 확인했습니다. 실제 Chrome의 권한·고양이 클릭·사이드 패널 실행, AI 답변 품질과 장기 학습 효과는 기기/사용자 평가가 필요합니다. 공개 고양이 디자인 미리보기는 모의 동작이며 실제 사이트 권한이나 API를 사용하지 않습니다.
