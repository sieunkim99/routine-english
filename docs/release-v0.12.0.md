# RoutineEnglish 0.12.0

- 스몰톡의 짧은 의견 버튼 2–3개: 매번 문장을 입력하지 않고 참여. 내 말로 음성/텍스트 응답도 가능.
- 최대 세 번 응답 후 자연스러운 다른 표현/확장과 다음 복습 제공. 선택한 표현을 독립 생성 실력으로 평가하지 않음.
- 현재 화면의 본문 또는 선택 문장 우선, 실제 원문 인용 근거 검사 및 펼쳐보기. 개인 목표가 현재 소재를 덮지 않도록 프롬프트 강화.
- API 연결 뒤 목표 설정 생략 가능. 목표·관심사·맥락은 나중에 설정에서 추가. 생략 시 수준 미평가.
- 첫 학습 화면에 고양이 켜기/다시 표시. 기존 탭 재주입과 사이트 CSS에 대한 표시 안정성 보완. 선택적 사이트 권한 필요.
- README, 스터디 가이드, 실제 프롬프트 문서 업데이트.

검증: 자동 검사 45개, 확장/웹/ZIP 빌드 및 브라우저 미리보기의 목표 생략→버튼 응답→종료 피드백 흐름 확인. 실제 API·마이크·사용자 Chrome에 설치된 고양이는 이 환경에서 실사용 확인하지 않음.

업데이트: 새 ZIP을 기존 폴더에 교체하고 chrome://extensions에서 새로고침 후 웹페이지도 새로고침. 같은 폴더를 유지하면 설정과 기록이 유지됩니다.
