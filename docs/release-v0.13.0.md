# RoutineEnglish 0.13.0

첫 반응은 선택으로 쉽게 시작하고 다음에는 단어나 짧은 구를 직접 표현합니다. 마지막은 현재 소재의 작은 상황 변화로 이어지며 최대 세 번 응답 후 표현 피드백으로 끝납니다.

- 이후 선택지는 기본 숨김, 작은 힌트/답변 보기는 요청 즉시 제공. 추가 AI 호출 없음.
- 응답별 보기 노출/힌트/선택 기록, 숨겨진 선택지는 노출 근거에서 제외.
- 현재 화면 소재 유지, 실제 의미 기반 자연스러운 표현 피드백, 답을 보기 전 회상하는 간격 복습.
- 목표 설정 생략 및 나중에 추가, 고양이 켜기/다시 표시 유지.
- README·스터디 가이드·설계·프롬프트 문서 업데이트.

검증: 자동 검사 48개, 빌드 및 브라우저 미리보기 흐름 확인. 실제 API와 마이크는 이번 확인에 포함되지 않았습니다.

업데이트: ZIP을 기존 설치 폴더에 교체 → chrome://extensions 새로고침 → 코치 화면 다시 열기.
