# Dear Meow 0.14.0 🐾

내 이야기를 영어로 풀어주는, 기억하는 고양이. 기존 RoutineEnglish의 설정과 기록을 유지하면서 Dear Meow로 업데이트했습니다. 저장소와 설치 ZIP의 경로는 기존 링크를 유지합니다.

- 검은 머리·흰 가르마 무늬 고양이, 선택적 이름 설정과 영어 관심사 키워드.
- 몰래 도움창: 한국어/영어로 뜻 전달 또는 생각 탐색 → 문장·핵심 표현·설명 → 원래 질문에 직접 적용. 초안 자동 제출 없음. 한국어 음성 초안 인식도 지원.
- 한국어 해석·설명 보기/숨기기 상태 기억. 복습 상황 단서는 별도 유지.
- 세 번 응답은 체크포인트, 계속 대화 가능. 여섯 번 이상 응답 후 점수와 무관하게 츄르 주기. 기지개·귀여운 자세·조용히 웅크리기·츄르 반응.
- 마지막 문장뿐 아니라 실제로 다듬은 표현·말하기 어려웠던 표현·잘한 문장을 대화 전체에서 모아 복습. 저장 제외/중복 합치기, 카드별 독립 일정과 피드백.
- 명시적 이야기 기억과 삭제, 현재 화면/지난 이야기 선택. 현재 페이지를 기본 소재로 유지.
- README·사용자 가이드·데이터 안내·실제 프롬프트 업데이트.

검증: 자동 검사 54개, 패키지 빌드, 브라우저 예시의 이름/관심사→몰래 도움→직접 답하기→긴 대화→츄르→여러 카드 흐름 및 고양이 디자인/동작 확인. 실제 OpenAI 품질·마이크·사용자의 설치된 Chrome 동작은 별도 실사용 확인이 필요합니다.

업데이트: ZIP을 기존 설치 폴더에 교체 → chrome://extensions 새로고침 → 코치 화면과 웹페이지 새로고침. 진행 중 옛 대화는 닫고 새로 시작하세요. 본인 API 키 방식이며 도움창·대화 요청에는 API 요금이 발생합니다.
