# Dear Meow 0.15.0

대화는 빈 텍스트 입력창과 ‘몰래 도움받기’ 중심으로 단순화했습니다.

- 처음부터 직접 영어 문장으로 답하기. 음성은 선택적으로 전환. 기존 설치도 이번 업데이트 때 한 번 텍스트 기본으로 전환.
- 답변 선택지와 단순 단어 힌트 제거. AI 출력 schema와 프롬프트에서도 일반 대화의 답변 예시 생성 금지.
- 막힐 때 몰래 도움받기→한국어로 뜻 전달→문장/핵심 표현 배우기→직접 사용.
- 긴 대화·표현 피드백·츄르·개인 표현 복습·이야기 기억 유지.
- README·사용자 가이드·프롬프트 문서 업데이트.

자동 검사 55개 및 빌드, 브라우저 예시 대화에서 기본 텍스트 입력과 도움 버튼 확인. 실제 AI 응답과 마이크 품질은 별도 실사용 확인이 필요합니다.

ZIP을 기존 폴더에 교체하고 Chrome 확장과 웹페이지를 새로고침하세요.
