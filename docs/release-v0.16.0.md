# MeowChat 0.16.0

- 서비스 이름을 MeowChat으로 변경. 저장소 URL과 로컬 기록은 기존 것을 유지합니다.
- 현재 화면 다시 읽기: 같은 URL의 게시물/스크롤 변화도 읽고, 새 내용을 확인한 뒤 기존 피드백을 저장하며 새 대화로 전환. 다시 읽기는 AI 호출 없음.
- 여러 게시물의 첫 article만 읽는 문제를 완화하고 main 본문/화면 내 텍스트 우선.
- 한국어 해석 기본 숨김, 필요할 때 펼치기. 기존 기본도 한 번 숨김으로 전환, 이후 선택 유지.
- 오늘 저장한 대화 응답·서로 다른 표현 복습에 따라 꼬리→기지개→신난 움직임. 실력/정답률과 분리하며 반복 버튼 누르기는 중복 계산하지 않습니다.
- 화면별 읽기 가이드, README·사용자 가이드·데이터 안내와 서비스 소개 이름 업데이트.

검증: 자동 검사 59개, 빌드 및 브라우저 예시 확인. 실제 AI 응답 품질과 사용자 Chrome에서의 페이지별 정확도는 별도 확인이 필요합니다.

업데이트: ZIP을 기존 설치 폴더에 교체하고 Chrome 확장과 웹페이지를 새로고침하세요.
