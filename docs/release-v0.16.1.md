# MeowChat 0.16.1 · 화면 근거 오류 수정

- 자유롭게 생성한 인용을 대조하던 방식을 수정했습니다. 실제 본문에서 만든 후보를 구조화 출력의 enum으로 지정하고 AI가 그중 하나를 선택합니다. 관련 없는 인용은 계속 차단합니다.
- 한국어 분해/조합 표기·공백·인용부호의 동등한 차이는 원래 후보로 정규화합니다.
- 검색창에 포커스가 있어도 입력 값과 입력란 선택은 제외하고 검색 결과 등 나머지 본문을 읽습니다.
- 본문을 못 읽어 사이트 이름만 가져왔을 때 안내합니다. Google 홈·보호된 화면처럼 읽을 본문이 없는 경우는 여전히 사이트 정보만 사용합니다.
- 화면 읽기 가이드와 실제 프롬프트 문서를 업데이트했습니다.

검증: 자동 검사 62개, 빌드. 실제 사용자의 AI 응답과 Google 화면은 직접 확인하지 않았습니다.

새 ZIP을 기존 설치 폴더에 교체 → chrome://extensions 새로고침 → MeowChat 대화창을 닫았다 다시 열고 웹페이지 새로고침. 기존 키와 기록은 유지합니다.
