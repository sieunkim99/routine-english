RoutineEnglish 첫 공개 버전입니다.

1. 아래 `routine-english-extension.zip`을 다운로드하고 압축을 해제합니다.
2. Chrome 주소창에 `chrome://extensions` 입력 → 개발자 모드 켜기 → 압축해제된 확장 프로그램 로드 → `manifest.json`이 있는 폴더 선택.
3. 자동으로 열리는 설정 페이지에서 데이터 전달 안내에 동의하고 본인의 OpenAI API 키를 입력합니다. API 키 검증과 학습 요청은 본인 계정에 사용 요금이 발생합니다.
4. 영어 채팅 또는 음성으로 원하는 목표를 이야기합니다. AI가 그 대화에서 임시 출발 수준과 목표를 함께 파악하고 커리큘럼을 제안합니다. 사용자는 방향을 확인하거나 대화로 수정합니다.
5. 평소 웹페이지에서 확장 아이콘을 누르면 ‘현재 페이지로 대화’와 ‘복습’을 사용할 수 있습니다. 설정한 간격에 학습 알림도 제안합니다.

서버 실행이나 연결 코드는 필요 없습니다. 설정은 확장에 포함된 웹페이지에서 한 번 진행합니다.

이 릴리스는 개발자 모드로 설치하는 공개 확장 파일이며 Chrome 웹 스토어 등록본은 아닙니다. 제공된 키는 없습니다. 각자 유효한 개인 API 키를 입력해야 실제 AI 대화를 사용할 수 있습니다. 웹 미리보기는 고정 예시이며 실제 AI 대화가 아닙니다.

자동 테스트 15개, 빌드와 ZIP 무결성 검사를 통과했습니다. 실제 개인 API 키를 통한 대화 품질·마이크·운영체제 알림은 설치 후 기기에서 확인해야 합니다.
