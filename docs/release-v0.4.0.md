## RoutineEnglish 0.4.0 — 음성으로 이어지는 영어 코치

- 기본을 음성 대화로 바꿨습니다. 코치가 질문을 읽고 사용자의 말을 듣습니다. 원하면 ‘텍스트로 채팅하기’로 전환할 수 있습니다.
- 잠깐 쉬었다고 응답을 보내지 않습니다. 연속 음성 인식과 자동 재연결로 전사를 유지하고, 사용자가 ‘말하기 완료 · 보내기’를 눌렀을 때 제출합니다.
- 코치가 말할 때 마이크를 중단해 자기 음성을 다시 인식하지 않게 합니다. 텍스트로 전환하거나 페이지를 떠나면 녹음과 재연결을 중단합니다.
- 첫 질문을 최근 영어가 필요했던 실제 순간에서 시작하게 바꿨습니다. 원하는 미래 모습, 개인적 이유, 현재 어려움과 관심사를 목표 및 커리큘럼에 반영합니다. 계획의 각 능력에도 개인적 연결 이유를 표시합니다.
- 앱의 15분 알림 최소 제한을 없앴습니다. 0보다 큰 소수도 입력할 수 있습니다. Chrome 일반 배포의 실제 예약 알림은 최소 30초이며 더 늦어질 수 있습니다.

### 설치 / 업데이트

1. 아래 ZIP을 다운로드하고 압축을 풉니다.
2. `chrome://extensions` → 개발자 모드 → 압축해제된 확장 프로그램 로드 → `manifest.json`이 있는 폴더 선택.
3. 기존 설치 폴더의 파일을 교체했다면 확장 관리 화면에서 새로고침하세요. 기존 API 키·목표·학습 기록은 유지되며 기본 입력 방식은 음성으로 바뀝니다.
4. 처음 음성 대화를 시작할 때 마이크를 허용하세요. 브라우저의 음성 인식 제공자는 오디오를 처리할 수 있습니다. 코치 읽어주기는 브라우저 음성 합성을 사용합니다.

Chrome 120 이상이 필요합니다. 개인 OpenAI API 키를 사용하며 API 요금은 본인 계정에 발생합니다. OpenAI Realtime 오디오가 아닌 차례로 말하는 브라우저 음성 대화입니다.

자동 테스트 24개, 빌드, ZIP 검사를 통과했습니다. 실제 API 응답 품질·기기의 마이크/음성 합성/운영체제 알림은 설치 후 확인이 필요합니다. 질문 설계의 학습 동기 효과는 사용자 스터디에서 검증해야 합니다.
