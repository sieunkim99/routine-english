## RoutineEnglish 0.4.1 — 자연스러운 코치 목소리

- 첫 번째 영어 음성을 무조건 고르는 대신 Google US English, Samantha 등 일반 대화용 음성을 우선 선택합니다. 알려진 효과음·특수 목소리는 제외합니다.
- 말하는 속도와 음높이를 기본값으로 맞췄습니다.
- Chrome의 음성 목록이 늦게 준비되는 경우 잠시 기다린 뒤 선택하며, 취소한 음성은 뒤늦게 재생하지 않습니다.

기기에 설치된 브라우저 음성을 사용하므로 실제 목소리는 운영체제와 Chrome 환경에 따라 달라집니다. 음성 API 추가 비용은 없습니다.

업데이트: ZIP 압축을 풀어 기존 설치 폴더의 파일을 교체하고 `chrome://extensions`에서 새로고침한 뒤 열려 있던 코치 화면도 다시 여세요. 동일한 설치 폴더를 유지하면 기존 API 키와 학습 기록을 계속 사용합니다.
