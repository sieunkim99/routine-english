## RoutineEnglish 0.5.0 — 작은 시도에서 다음 복습까지

Notion 기획의 Understand → Plan → Act → Observe → Adapt를 바탕으로 교육·심리 기반 프롬프트를 분리하고 실제 AI 요청에 적용했습니다.

- 하나의 목표에 집중해 ‘먼저 표현 → 필요한 지원과 수정 → 준비되면 다른 상황에 적용’하도록 지시합니다.
- 막히거나 도움을 요청하면 부분 단서·짧은 예시로 부담을 줄입니다. 도움을 받기 위한 반복 실패를 요구하지 않습니다.
- 한 번에 하나의 개선에 집중하며 유효한 다른 표현을 인정합니다. 음성 전사로 발음을 평가하지 않습니다.
- 현재 응답 수, 최근 능력 ID·도움 여부를 전달하고 힌트 사용 시 독립 수행 점수 2를 코드에서도 제한합니다.
- 복습 제안은 회상·힌트·미루기 선택을 안내합니다. 알림을 위한 추가 모델 호출은 없습니다.
- 설계 근거, 전체 영어 프롬프트, 대화 예시, 14개 평가 상황을 `docs/COACH_PROMPTS.md`에 정리했습니다.

자동 테스트 29개와 설치 ZIP 빌드를 확인했습니다. 실제 API 응답의 일관성 및 장기 학습 효과는 별도 평가가 필요합니다. 미리보기는 고정된 예시이며, 새 프롬프트는 설치된 확장의 실제 AI 대화에 적용됩니다.

업데이트: ZIP을 풀어 기존 설치 폴더 파일을 교체하고 `chrome://extensions`에서 새로고침하세요. 열려 있는 코치 화면도 다시 여세요. 동일한 설치 폴더를 유지하면 API 키·목표·기록은 유지됩니다.
