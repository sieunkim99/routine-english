## RoutineEnglish 0.5.1 — 짧은 첫 대화와 영어 피드백

- 코치 음성에서 **, 밑줄, 백틱, 제목·목록 기호 등 마크다운 표기를 제거하고 본문만 읽습니다.
- 처음 설정을 기본 세 번의 응답으로 제한합니다: 일상/학업/직업 맥락 → 영어 사용 장면 → 짧은 영어 표현.
- 세 번째 답변 뒤에는 추가 질문 대신 영어 피드백과 세 가지 맞춤 능력을 제안하도록 JSON 응답 형식에서도 제한합니다. 정보가 부족하면 임시 계획을 제시합니다.
- 실제 답변의 강점, 개선 하나, 표현 예시를 영어로 보여주고 읽어준 뒤 계획을 승인할 수 있습니다.
- 생활 맥락을 프로필에 저장해 다음 연습에도 사용합니다. 진행 중이던 긴 설정 대화도 다음 답변에서 마무리하도록 처리합니다.

기존 설치 폴더에 ZIP 내용을 교체하고 chrome://extensions에서 새로고침한 뒤 코치 화면을 다시 여세요. API 키와 기존 학습 기록은 유지됩니다.

자동 테스트와 빌드로 흐름을 확인했습니다. 실제 모델 답변 품질과 기기 음성은 추가 사용 확인이 필요합니다.
