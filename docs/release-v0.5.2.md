## RoutineEnglish 0.5.2 — 한국어 페이지도 영어 대화 소재로

- Chrome에서 확인한 한국어 Notion 페이지는 본문이 편집 가능한 블록에 들어 있어 기존 추출기가 내용을 건너뛰었습니다. Notion의 보이는 페이지 블록을 읽도록 수정했습니다.
- 페이지 본문이 한국어일 때 코치는 실제 내용의 한 가지 생각·설명·반응을 영어로 표현하도록 질문합니다. 전체 페이지 번역이나 암기를 요구하지 않습니다.
- 현재 선택한 문단을 우선 사용합니다. 연구 노트처럼 긴 Notion 페이지라면 연습하고 싶은 문단을 선택한 뒤 확장 아이콘을 누르면 더 정확합니다.

기존 설치 폴더의 파일을 ZIP 내용으로 교체하고 `chrome://extensions`에서 새로고침한 뒤 페이지에서 확장 아이콘을 다시 누르세요. API 키와 학습 기록은 유지됩니다.

모의 Notion 블록·한국어 입력 검증을 포함한 자동 테스트 34개가 통과했습니다. 실제 Notion 화면과 모델 응답은 사용 중인 기기에서 다시 확인해야 합니다.
