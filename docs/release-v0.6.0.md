## RoutineEnglish 0.6.0 — 지금 하는 일로 영어 연습

- 인스타그램처럼 읽을 본문이 없는 일반 웹페이지에서도 사이트 정보만으로 학습을 시작할 수 있습니다. 코치는 게시물이나 이미지를 봤다고 주장하지 않고, 사용자가 지금 무엇을 하는지 영어로 표현하도록 묻습니다.
- 일반 웹페이지에서 Mac **⌘⇧Y**, Windows/Linux **Ctrl+Shift+Y** 단축키로 아이콘 없이 코치를 열고 해당 탭에 대한 일시적 접근을 허용할 수 있습니다. 다른 확장과 충돌하면 `chrome://extensions/shortcuts`에서 변경하세요.
- 아이콘을 사용하려면 Chrome 오른쪽 위 퍼즐 모양 **확장 프로그램** 메뉴에서 RoutineEnglish을 고정하세요.
- 패널의 안내 문구를 ‘본문 읽기’에만 한정하지 않고 현재 웹페이지 활동에도 맞게 수정했습니다.

이미지 분석, 인스타그램 피드 감시, 백그라운드 페이지 수집은 포함하지 않습니다. 페이지를 명시적으로 열었을 때만 가능한 정보를 사용합니다. Chrome 내부 페이지에서는 동작하지 않습니다.

ZIP을 풀어 기존 설치 폴더의 파일을 교체하고 `chrome://extensions`에서 새로고침한 뒤 사용하세요. API 키와 학습 기록은 유지됩니다.
