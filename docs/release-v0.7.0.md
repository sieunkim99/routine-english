## RoutineEnglish 0.7.0 — 작은 표현에서 시작하는 학습

- 전체 문장 대신 짧은 표현 선택·빈칸 회상·개인화한 단어/구로 연습할 수 있습니다. 코치가 형태를 골라 화면에 표시합니다.
- 새 표현은 알아보기부터, 이미 본 표현과 복습은 회상부터 시작하도록 지시합니다. 막히면 도움을 늘리고, 성공하면 선택지를 줄입니다.
- 사이트 이름이나 직업만으로 주제를 정하지 않고 본문의 구체적 행동·결정·반응과 사용자 목표·관심사를 연결하도록 프롬프트를 수정했습니다.
- 실제 연습한 chunk와 응답 형태를 기록해 이후 복습에 전달합니다. 선택형만 성공한 기록은 독립 회상으로 평가하지 않습니다.
- 선택형은 마이크를 켜지 않고 바로 시작할 수 있습니다. 원하면 음성으로 읽어주는 코치에 말로 답할 수도 있습니다.

교육 근거와 예시: docs/CHUNK_LEARNING.md. 설치 ZIP 내용을 기존 폴더에 교체하고 chrome://extensions에서 새로고침한 뒤 코치 화면을 다시 여세요.
