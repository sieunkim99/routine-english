## RoutineEnglish 0.8.0 — 현재 글을 먼저, 제안은 내 시간에

- 주제를 정할 때 현재 페이지의 실제 내용을 최우선으로 씁니다. 연구 목표를 가진 사용자도 책방·문학상 글에서는 독서와 문학에 대한 표현을 연습합니다. 목표와 커리큘럼은 난이도·대화 능력을 조절합니다.
- 처음 설정 대화에서 일상 관심사도 묻고, 직업/학업 목표를 생활 전반의 유일한 주제로 취급하지 않습니다. 기존 목표는 보존하며 현재 글을 우선하는 새 지침은 새 학습부터 적용됩니다.
- 제안 설정에서 ‘작은 채팅창 팝업’과 ‘정해진 시각’을 선택할 수 있습니다. 예: 14:00, 18:30. 기존 간격/시스템 알림도 선택 가능합니다.
- 코치 화면의 ‘회의 전 방해금지’에서 기본 60분, 빠른 30분, 직접 정한 분 동안 이 서비스의 제안을 쉽니다. 남은 종료 시각과 해제 버튼을 표시합니다.
- 학습 중·컴퓨터가 쉬거나 잠김·방해금지 중에는 제안하지 않습니다. 팝업이 이미 열려 있으면 중복 생성하지 않습니다. 방해금지를 켜면 열린 제안 팝업과 알림도 닫습니다.

팝업은 소리 없이 여는 작은 Chrome 창이며 사용자가 시작을 누르기 전에는 AI를 호출하지 않습니다. 자동으로 현재 페이지 본문을 읽는 권한은 추가하지 않았습니다. 과거 기록이 있으면 복습을 제안하고, 없으면 현재 행동을 확인하는 가벼운 학습을 시작합니다. 현재 페이지의 자세한 내용을 쓰려면 해당 탭에서 아이콘/단축키로 열어주세요.

예약 시각은 기기의 현지 시간과 설정된 시작–종료 시간 안에서 사용합니다. Chrome이 실행 중이어야 하며 실제 팝업은 지연될 수 있습니다. 예약 시각 이후 5분 안에만 한 번 제안하고 방해금지로 건너뛴 것을 나중에 몰아서 보여주지 않습니다. 자동 회의 감지/시스템 전체 방해금지와는 별개의 코치 제안 설정입니다.

자동 테스트 39개를 통과했습니다. 실제 모델의 소재 선택과 OS에서의 팝업 표시 방식은 설치 후 확인이 필요합니다.

업데이트: 기존 설치 폴더에 ZIP 내용을 교체 → chrome://extensions에서 새로고침 → 코치 화면 다시 열기. 학습 설정에서 원하는 제안 방식과 시각을 선택하세요.
