## RoutineEnglish 0.9.0 — 먼저 스몰톡, 끝나면 표현 배우기

- 현재 화면에서 읽은 내용으로 코치와 짧은 영어 스몰톡을 합니다. 첫 화면에서 선택형·빈칸 과제를 강요하지 않습니다.
- 단어·짧은 구도 받아주고 뜻에 반응하며 대화를 이어갑니다. 대화 도중 교정은 미루고, 도움을 요청하거나 뜻이 불명확할 때만 바로 돕습니다.
- 대화를 마치면 실제 사용자 표현과 자연스러운 대안 하나를 보여줍니다. 이미 자연스러우면 선택 가능한 확장으로 설명합니다. 실제로 하지 않은 말을 사용자 발언으로 인용하지 못하도록 확인합니다.
- 대화 끝에 얻은 chunk를 저장해 다음 날 이후 복습합니다. 복습에서는 회상·빈칸·짧은 응답 형식을 활용합니다.
- 예약 팝업과 방해금지는 유지됩니다.

기존 폴더에 ZIP 내용을 교체하고 chrome://extensions에서 새로고침한 뒤 코치 화면을 다시 여세요. 이전에 진행 중이던 연습은 닫고 새로 시작해야 새 흐름이 적용됩니다.

자동 테스트 40개와 빌드를 확인했습니다. 실제 모델의 대화·표현 제안 품질과 학습 효과는 추가 확인이 필요합니다.
